## How to Host Independently (Away from Lovable)

To have this website running on your own domain (e.g., `hiba-alsaydeah.com` or `yourname.github.io`), follow these steps:

### Option 1: GitHub Pages (Free)
1. **Create a GitHub account** if you don't have one.
2. **Create a new repository** named `hiba-alsaydeah.github.io`.
3. **Upload all these files** to that repository.
4. Your site will be live at `https://hiba-alsaydeah.github.io` automatically!
5. To use a **custom domain**: Go to repository **Settings > Pages** and add your domain.

### Option 2: Netlify or Vercel (Recommended)
1. Sign up for [Netlify](https://www.netlify.com/) or [Vercel](https://vercel.com/).
2. Drag and drop the project folder into their dashboard.
3. They will provide a link, and you can easily connect your own domain through their settings.
